TRUST STARTS WITH WHAT WE KNOW

A growing corpus, with honest labels.

Imported ≠ verified

Imported records are labelled unverified. Historical confidence numbers and generated grammar metadata are not evidence of a speaker’s review.

Sources stay visible

Each record shows its available source information. Some recovered records have only artifact-level provenance; missing upstream attribution and licences are explicitly unknown.

Context before claims

Corpus phrases are not automatically dictionary definitions, usage examples, or generated translations. Editor review is separate from native-speaker verification.

No bulk dataset export is offered here. Upstream licences must be audited before redistribution. The public lookup API is documented at /openapi.json.

Editor review

Authorized editors can review pending submissions. This marks an entry as editor-reviewed, not native-speaker verified.
